English 中文

一套方便 Agent 接入的自托管监控系统，覆盖 AI 服务与 Web3。

  • Agent 可直接接入。 提供 REST、MCP 和 Skills，让 Agent 能查询服务状态、创建监控。
  • AI 服务。 可监控 API 和模型端点。
  • Web3（Crypto）。 在 EVM 链上检查账户余额、RPC 数据是否及时更新，以及指定合约的返回值。
  • 基于 Tailwind CSS 的全新界面。 提供更丰富的主题和更现代的公开状态页。

一条命令，部署到你自己的机器上。

docker run -d --restart=always -p 3001:3001 -v uptime-gizmo:/app/data --name uptime-gizmo starit/uptime-gizmo:beta
