Self-hosted monitoring that is agent-friendly, and that watches AI services and Web3 (crypto).

  • Agent-friendly. REST, MCP, and skills. An agent can see what is down, and create monitors.
  • AI services. Watch an API or a model endpoint.
  • Web3 (crypto). On-chain, EVM checks for balances, RPC freshness, and one contract value.
  • UI rebuilt in Tailwind CSS. Richer themes, and a more modern public status page.

One to go — runs on your machine.

docker run -d --restart=always -p 3001:3001 -v uptime-gizmo:/app/data --name uptime-gizmo starit/uptime-gizmo:beta
