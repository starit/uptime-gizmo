github.com/starit/uptime-gizmo

Self-hosted monitoring. A fork of Uptime Kuma with an API for agents, EVM checks, and a rebuilt interface.

  • REST, MCP, skills. Agents can see what is down, and create monitors.
  • Web3, EVM only. Balances, RPC freshness, one contract value.
  • Rebuilt UI. Light, dark, and a public status page.

One to go — runs on your machine.

docker run -d --restart=always -p 3001:3001 -v uptime-gizmo:/app/data --name uptime-gizmo starit/uptime-gizmo:beta
