# Uptime Gizmo Instructions

Follow [AGENTS.md](./AGENTS.md) as the primary contribution and code-agent guide for this repository.

## Project context

Uptime Gizmo is a fork of Uptime Gizmo focused on modern monitoring, status pages, automation, and AI-agent-friendly workflows. The repository contains a Vue frontend and a Node.js backend.

## Additional guidance

- Prefer focused, reviewable changes over broad rewrites.
- Confirm whether a capability exists before describing it as available; label roadmap work as planned.
- Follow [DESIGN.md](DESIGN.md) for the approved brand assets, light and dark theme tokens, semantic status colors, accessibility requirements, and UI implementation checklist.
- When changing the UI, preserve existing functionality and verify the affected states manually in both themes when the change is visual.
- Keep user-provided assets and unrelated working-tree changes intact.
- Before handing work back, summarize the files changed and the verification performed.
